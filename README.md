# synv3x — Cybersecurity Portfolio

Personal portfolio for **synv3x**, a cybersecurity learner based in Toronto.
Built with vanilla **HTML, CSS, and JavaScript** — no frameworks, no build step.

🔗 **Live:** https://synv3x.github.io

## Highlights

- Animated access gate and an interactive particle-network background
- Fully responsive, mobile-first layout with touch interactions
- Sections: About · Skills · Toolbox · Projects · Roadmap · Contact
- Respects `prefers-reduced-motion` for accessibility

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Built with

HTML5 · CSS3 · JavaScript (Canvas API)

## Structure

```
index.html    # markup
styles.css    # all styling
script.js     # interactions, animations, canvas background
profile.png   # avatar
```
